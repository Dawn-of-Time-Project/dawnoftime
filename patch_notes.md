## **🌅 Dawn of Time Forge/Fabric 1.20.1 v1.5.54**

![](https://i.imgur.com/17mJdAC.png)

### Entirely new German building set, the Rustic one!
- Lime wattle and daub set to craft the new timber frames
- Weathered oak set : stripped weathered oak log, oak planks, plus stairs, slab, plate, edge and trapdoor
- Weathered oak timber frame (complete set)
- Weathered oak timber frame fancy: simple decorative cube (no connected texture)
- Red painted oak set : stripped red painted oak log (red dye and 8 stripped oak logs, gives 8) and red painted oak planks (1 log gives 4), plus stairs, slab, plate and edge
- Red oak timber frame (complete set)
- Red painted oak shutters
- Yellow wattle and daub to craft the yellow timber frame set
- Yellow oak timber frame (complete set)
- Green painted oak shutters
- Green painted oak door 
- White painted oak window : single (non connected) glazed window
- Copper roof tiles set  (block, stairs, plate, slab, edge)
- Calcite powder (calcite cooked in a furnace or blast furnace) 
- Lime, used to craft the new wattle and daub for the set
- Yellow pigmented lime  (calcite powder, water bucket, weathered oak slabs, yellow dye and orange dye, gives 32) and yellow wattle and daub set (block, stairs, plate, slab, edge)
### Other cultures:
- Precolumbian: Green, Blue, Yellow plastered stone window & column and Blue Lattice
- Chinese: Added a custom recipe to the Green roof tiles and updated the texture. You can now craft the block by firing a green round clay tile
- Roman: 3x3 connected birch window
- Japanese: 3x3 connected paper wall window
### Improvements:
- Plates (all cultures) are now considered as full blocks for support checks: glass panes, iron bars and paper walls connect to their sides
- Tooltips reworked: updated all tooltips across the blocks to make the system more clean and readable, some blocks missed their tooltips too
- Various recipe changes to include new items or unify the recipes across similar blocks
- Mob pathfinding: land mobs (villagers, zombies...) now treat all DoT blocks as solid and go around them instead of getting stuck
### Fixes:
- Painted stone stairs (white, red, blue, green, yellow): fixed the rotation of upside-down inner/outer corners
- Irori fireplace (off): removed 20 misplaced culling tags that hid parts of the log next to solid blocks
- Removed leftover files of unregistered blocks (it was more or less a cemetery of half broken and injured blocks, sry boyz you fought well but you didnt make it to the finish line)
